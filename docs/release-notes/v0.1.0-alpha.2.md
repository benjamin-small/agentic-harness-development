# 0.1.0-alpha.2

Jev is now available as a TypeScript library and command-line tool. One request can ask multiple typed questions over shared state; JSONL batches stream correlated results with bounded concurrency, cancellation, deadlines, validated responses, and controlled retries. The model is pinned to `typesafe/jev-1.13` through OpenRouter's alpha Decisions API.

Install the attached package tarball using the [bootstrap guide](https://github.com/benjamin-small/agentic-harness-development/blob/v0.1.0-alpha.2/BOOTSTRAP.md). It provides both `harness-kit` and `jev`, plus the root catalog library and `/jev` client export. The source archive, manifest, and checksums identify the exact release. Node.js 24 or 26 is required; nothing is published to npm.

Every skill and agent now owns indexed `knowledge/` and `memory/` directories. The skill/agent paths and catalog schema have changed from alpha.1: use the matching schema-2 reader and regenerate plans. Keep private working expertise under the owning component's ignored `knowledge/local/` and `memory/local/` directories, outside immutable release caches. Do not overwrite local material during upgrades.

Contract, fault, CLI, and isolated artifact-consumer checks use synthetic fixtures. **Live OpenRouter verification is pending** because no key was available. A one-attempt, opt-in smoke script is provided in the source archive. Paid API calls require injected credentials; installation and local validation do not invoke inference.

Automatic project detection, installation writes, native agent/Pi adapters, and persistent services remain future milestones. The catalog planner is still read-only.
