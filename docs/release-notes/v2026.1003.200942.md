# v2026.1003.200942

Make Jev easier for agents to select and use through the existing client, reusable recipes, and native tool discovery.

- Add `evidence_relevance` and `finding_support` recipes through the library and CLI, plus an opt-in `jev-mcp` stdio interface with six tools. Recipe/MCP inference defaults to zero retries; bounded batches have an internal deadline and explicit cancellation limits.
- Return persistent call IDs and record allowlisted recipe metadata and caller-reported outcomes. Logs show whether answers were used, overridden, or unavailable without recording request text or credentials.
- Add concrete default-use triggers, a Jev dependency and execution packet for UI reviewers, and outcome reporting for specialist reviews. Four portable harness compatibility reviewers and the repository review workflow are included.
- Add an opt-in native Codex adoption evaluation using synthetic tasks and a mock provider. Arithmetic and prose remain negative controls; no compaction hook or measured speed gain is claimed.
- Rename the portable `update` skill to `poietic-harness-update`. The generated Claude maintenance plugin retains `/poietic-harness:update`.
- Keep startup version checks working with the larger dependency lockfile while retaining bounded metadata reads.

Migration: install the complete selected skills and runtime from this release, preserving private `knowledge/local/` and `memory/local/` directories. Migrate existing portable `update` directories and installation records to `poietic-harness-update`, then verify discovery before retiring the old copy. UI reviewer selections now require Jev; explicit dependency exclusions fail visibly. Existing `jev decide` and `batch` interfaces remain supported.

Native Jev tools require explicit host registration and may require a session reload. Credentials and provider-data authorization remain host-owned. Register an absolute pinned `jev-mcp` path and provision a writable persistent log. See [MCP setup](https://github.com/benjamin-small/agentic-harness-development/blob/v2026.1003.200942/docs/jev-mcp.md) for bounded execution, declared data scopes, credential-file requirements, and cancellation behavior. Installation alone does not authorize inference or private data disclosure.

Validation: 85 automated tests and nine catalog components; native Codex discovery, four synthetic adoption cases, and bounded live synthetic MCP requests were checked. Four fresh-context specialist reviews found and verified repairs for disconnect cancellation, duplicate feedback, invalid credential FIFOs, and batch cancellation/deadline behavior. These reviewers ran under Codex; native Claude, Pi and OpenCode execution remain unverified. Caller-reported outcomes are not accuracy scores.
