# v2026.1003.142920

Provision startup checks once and reuse a deterministic command across sessions.

- Add a portable host-access contract: exact runtime/pin/cache paths, permissions, cold lookup and cache-hit verification, and explicit boundaries between checks and upgrades.
- Add a no-argument Codex helper for the standard personal layout. It validates the pinned runtime, uses a five-minute release cache and a bounded network request, and rejects caller-supplied commands or paths.
- Document a narrow Codex command rule, its trust boundary, and the restart required to load it. Other harnesses use their supported hooks/profiles/supervisors; no new native adapters are claimed.

Migration: install the complete startup skill, provision the reviewed helper and host grant during authorized setup, and record the command in private local knowledge. Do not change permissions every session or grant arbitrary shell access. Older installations can retain the manual checker until setup is completed. The Codex helper requires a runtime with poll (v2026.1002.2233 or later).

Validation: 71 tests, resource validation, fixed-command negative cases, local Codex rule evaluation, a real GitHub lookup, and a subsequent cache hit. Fresh-session prompt-free behavior remains to be confirmed after Codex reloads its rules. No paid inference or automatic update is part of startup.
