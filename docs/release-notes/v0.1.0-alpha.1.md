# v0.1.0-alpha.1 — Repository foundation

This first prerelease establishes the reusable skills-and-agents repository and the implementation plan.

## Available

- Jev guidance for typed questions, OpenRouter integration, result interpretation, and harness patterns.
- UI standards skill and a portable UI reviewer role for isolated task contexts.
- Validated component catalog, JSON Schema, and TypeScript library/CLI for explicit capability selection.
- User/project/deployment bootstrap instructions, contribution/security guidance, tests, and CI.
- Runtime package and source archives with a version/source manifest and SHA-256 checksums.

## Installation

Read [the versioned bootstrap guide](https://github.com/benjamin-small/agentic-harness-development/blob/v0.1.0-alpha.1/BOOTSTRAP.md). Use Node.js 24 LTS or 26. Verify checksums before installing the attached `.tgz`; no npm registry publication is required.

Personal installation uses user-owned skill directories and a versioned tool cache. Project installation selects applicable skills, including UI guidance only when relevant. Deployed agents consume explicit pinned artifacts during provisioning.

## Limits

The CLI is read-only. Jev API calls, automatic project inspection, installation writes, and native subagent adapters are not implemented. The UI reviewer is a canonical role document, not an automatically registered agent. No live Jev inference or native harness execution is claimed by this release. Persistent project-manager execution belongs in a separate future service.

Runtime validation covers schema/dependency/resource boundaries and CLI behavior. Release verification installs the exact package into an isolated consumer and checks library imports, resource loading, and the installed CLI.
